# Guardrails

What this agent must never do. The code guards still enforce the rules. This file tells the model.

- Never name a client contact or give an email address or phone number.
- Never cite an item from another client's area. Cite only playbook ids (PB-) and items of this deal's own area.
- Never present an unconfirmed item as sure. Label it Unconfirmed.
- Never leave out a kickoff checklist topic or an objection topic without a closing idea.
- Never use a fact that is not in the context.

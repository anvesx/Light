# Research

All research for Company OS goes in this folder: market checks, product comparisons, technical choices and focus groups. One file per topic. Each file says when it was written, who or what did the research, and which claims are confirmed or unverified.

| File | What it covers |
|---|---|
| `harness-decision-own-base-vs-dsh.md` | Why we build our own thin runtime instead of using DeepSeek's harness (dsh) |
| `plugin-harness-architecture.md` | How plugin-based agent harnesses are built |
| `grok-bot-and-always-on-agents.md` | xAI Grok Bot, Meta Muse, OpenAI Dots, OpenClaw and Hermes Agent: always-on agents, and ideas we copied |
| `grok-bot-internals-vs-company-os.md` | How Grok Bot works inside, compared with Company OS |
| `per-user-vms.md` | One cloud VM per user: agent boxes inside it, sign-in through a live view, hosting options and prices, cost |
| `enterprise-24x7-domains.md` | Where always-on agents help large companies |
| `personal-24x7-agents.md` | Always-on agents for individuals |
| `focus-group-run1-prototype.md` | Simulated focus group, run 1: 16 personas judged the prototype (they worried about dummy data) |
| `focus-group-run2-product-on-real-data.md` | Simulated focus group, run 2: the product idea on real data; finance first pick at 56% |

The focus groups are simulated: one AI model (Sonnet) played 16 fictional personas. They are useful for objections and ideas, not as proof of demand.
